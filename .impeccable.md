## Design Context

### Users
Disaster-management reviewers and meteorological operations teams evaluating SkyGuard AI in a live demo. They need to scan station health, spot abnormalities, and understand current conditions without waiting for a backend.

### Brand Personality
Assured, precise, protective. The interface should convey situational awareness and calm control.

### Aesthetic Direction
Light, operational command-centre UI using the existing SkyGuard blue palette. Demo data must be visibly framed as simulated and use plausible Indian AWS station names and readings.

### Design Principles
- Put actionable environmental state ahead of decorative information.
- Use severity colour only for a genuine warning or critical condition.
- Keep live-demo content readable at a glance and clearly label simulation mode.
- Design every state to be useful when the API is unavailable.
